# README 视觉素材来源

本轮 README 首屏与分节横条按维护者提供的 [MaiBot README](https://github.com/Mai-with-u/MaiBot) 截图复刻视觉结构：立体窗口边框、像素标题、通风栅格、状态灯、四格信息卡与键帽入口。对应项目的公开 SVG 用于核对布局和色值，未复制它的 SVG 路径、人物图、鱼形装饰、遥测数据或趋势排名徽章。

- 排版源稿：[hero.html](hero.html)。深浅主题 PNG 是真实 HTML / CSS 的静态截图，不是产品运行截图或生成式插图。
- 右侧角色：复用项目原始 [icon.png](../../icon.png)，未重画或重编码原图。
- 挂件：复用 [菲比啾比](../rope/phoebe.png)，未修改运行时 PNG。角色权利保持原有归属，本页不重新授权。
- 字体：Jersey 20，Copyright 2023 The Soft Type Project Authors。字体来自 [Google Fonts](https://github.com/google/fonts/tree/main/ofl/jersey20)，按 [SIL Open Font License 1.1](OFL-Jersey20.txt) 使用。原字体文件保留供复现，不作为插件运行依赖。
- 信息卡：源码版本来自项目包声明；三类 WE 壁纸为 Scene / Web / Video；十只立绘来自内置角色；七个子包来自项目子包清单。这些是当前源码信息，不是实时在线人数、下载遥测或门禁结果。
- 资源尺寸、摘要、实际截图元素与生成时间记录在 [metadata.json](metadata.json)，仅登记本轮实际使用的 56 份双主题展示图。旧创作桌面配饰不再用于横幅，未纳入本轮展示素材与发布包。
